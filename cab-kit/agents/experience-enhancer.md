## Step 2 — build rules (the kit is the only way to change a page)
- Change `cabs_data.py` / `build.py` / `hub.py` / `kit.js` / `kit.css` — never hand-edit WordPress content; `build.py` must keep succeeding for **every** page (`python3 build.py` with no args), because the Route Builder rebuilds the hub daily from the same code.
- `kit.js`: **no `&` character anywhere** (use `'\x26'` for query strings; nest `if`s instead of `&&`), no `//` comments, ES5 syntax, everything inside the IIFE, feature-detect (`if(el){…}`) because the same script runs on hub, route, city and vehicle pages. Page HTML inside JS strings must not contain a bare `<p>` tag (use `<p class="…">`).
- CSS stays scoped to `.szc` (plus `.szc-modal`, `.szc-pin`, `.szc-car` which are appended to `body`/map). Light theme, brand colours (emerald `#122615`, green `#2e7d32`, gold `#d4af37`), Plus Jakarta Sans.
- **Speed budget:** no new render-blocking assets; third-party JS only lazy-loaded on interaction/visibility (MapLibre is loaded only when the planner is used or scrolled near); images lazy with width/height; hub page HTML ≤ 180 KB, route pages ≤ 130 KB (before gzip). Measure before/after with PageSpeed (mobile) when you touch anything global; never ship a change that drops the mobile performance score by more than 3 points — revert instead.
- **Libraries:** only mature, maintained, permissive-licence libraries pinned to an exact version on jsDelivr (current: `maplibre-gl@5.24.0` UMD build — do not move to 6.x, it is ESM-only). Check the version's npm release date (≥ 2 weeks old) and that no known vulnerability is open for it before pinning. No jQuery plugins, no abandoned packages.
- **Free services the planner relies on** (all keyless; client-side from the visitor's browser): OpenFreeMap tiles (`tiles.openfreemap.org/styles/liberty`), OSRM routing at `routing.openstreetmap.de/routed-car` with `router.project-osrm.org` fallback, Photon geocoding (`photon.komoot.io`). Keep the attribution line. If one goes away, the planner must still degrade gracefully (straight-line estimate + WhatsApp) — test the fallback path, never leave a blank box. If usage ever grows beyond fair use (thousands of routes/day), propose a paid/free-tier key service (MapTiler, OpenRouteService, Stadia) as a "Sushil ke liye" decision — don't sign up for anything yourself.
- Map rule: **no state or national boundary lines** (the kit hides the `boundary` source-layer on load) and `maxBounds` stays on India — keep both after any style change.
- **Photos (legal):** only Wikimedia Commons files under CC0 / CC BY / CC BY-SA (record author, licence, licence URL, file page URL in `media.json → photos` and the credits block renders automatically), Suzu's own guest/car photos Sushil provides, or Pexels/Unsplash-licence photos. Never Google Images, dealer sites, aggregator pages or AI renders of real car models. Download the ≤1600-px Commons thumb, crop to 3:2 if needed, convert to WebP (q 80, ≤ 120 KB), commit under `cab-kit/media/fleet-photos/<id>.webp`, pin the SHA via `media.json` (`photos.<id>.src` = jsDelivr URL). - **Fares:** every price comes from the engine (`oneway()` / per-km × TIER multipliers). Tier multipliers (Prime 1.15, Standard 1.00, Saver 0.92), per-km rates and route factors are Sushil's decisions — never change them; propose with evidence in the report. Buses (`quote=True`) stay "On quote".
