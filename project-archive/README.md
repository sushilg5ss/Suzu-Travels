# Project archive (16 Oct 2026)

The Claude Project "Claude-HyperFrames" reached its 2 MB size limit. To make room, the old
`claude/adventure-pages/*.html` and `*.patch` docs were removed from the project
after Sushil approved it on 16 Oct 2026.

Those docs were the source of the live adventure pages. This folder keeps the full
live page for each one (rendered HTML fetched from suzutravels.com on 16 Oct 2026).
The page content itself still lives in WordPress, so nothing on the site changed.
The `gen_*.py` generator scripts were left in the project.
